# SpamazonBoard
A Python-Powered Mechanical "Keyboard" to order stuff off amazon at the press of a physical button

# Spamazon Prototype R1
Capabilities include:
- 4x6 (24 keys)
- Programmable via JSON file
- MUST BE HARD WIRED TO ANY EXTERNALLY INFLUENCED HARDWARE SUCH AS LED STRIPS, SMART BULBS, OR OTHER DEVICES
  - Cannot currently dispatch orders to the Amazon Order API
